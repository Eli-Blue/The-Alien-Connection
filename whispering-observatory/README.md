# The Whispering Observatory

A small, asset-free mystery adventure prototype for Solar2D. Explore an observatory, find hidden clues, unlock a celestial puzzle, and uncover the astronomer's final message.

## Run

Open this folder in the Solar2D Simulator. The project uses only `main.lua` and `config.lua`; no external art or audio is required.

## Play

- Tap **Begin Investigation**.
- Search the rug for a brass key and behind the portrait for a star chart.
- Use the key on the desk drawer to find the astronomer's note.
- Tap the telescope and set its dials to **Moon, Star, Sun**.

The interface is designed for a 360 × 640 portrait layout and scales with letterboxing.
